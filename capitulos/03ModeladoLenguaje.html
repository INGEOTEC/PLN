3.1 Introducción

Un modelo de lenguaje es una función que permite estimar la probabilidad de un texto, i.e., \(\mathbb P(w_1, w_2, \ldots, w_n).\) Comunmente, se trata de modelar \(\mathbb P(w_n \mid w_1, w_2, \ldots,w_{n-1}),\) es decir, encontrar una función que estime la probabilidad de la siguiente palabra o segmento, i.e., \(w_n\), dada la historia.

Realizando la suposición de Markov, es decir, que el segmento \(w_n\), es independiente de los segmentos iguales y mayores a \(N\), es decir, \(\mathbb P(w_n \mid w_1, w_2, \ldots,w_{n-1})=\mathbb P(w_n \mid w_{n-N+1}, \ldots, w_{n-1}),\) para \(N < n.\) Por ejemplo, para \(N=2\) el modelo con esta suposición quedaría como \(\mathbb P(w_n \mid w_{n-1})\), en el caso \(N=3\) sería: \(\mathbb P(w_n \mid w_{n-2}, w_{n-1})\) y así sucesivamente.

3.2 Modelo de lenguaje

En este caso el modelo para el siguiente segmento quedaría como

\[ \begin{split} \mathbb P(w_n \mid w_{n-N+1}, \ldots, w_{n-1})&=\frac{\#(w_{n-N+1}, \ldots, w_{n-1}, w_n)}{\sum_{\ell} \#(w_{n-N+1}, \ldots, w_{n-1}, \ell)}\\ &=\frac{\#(w_{n-N+1}, \ldots, w_{n-1}, w_n)}{\#(w_{n-N+1}, \ldots, w_{n-1})}, \end{split} \tag{3.1}\]

donde \(\#\) corresponde a la frecuencia medida en un conjunto de entrenamiento. Por ejemplo, para \(N=3\) la Ecuación 3.1 quedaría como

\[ \mathbb P(w_n \mid w_{n-2}, w_{n-1})=\frac{\#(w_{n-2}, w_{n-1}, w_n)}{\#(w_{n-2}, w_{n-1})}. \]

3.3.1 \(k\)-suavizado

Para poder calcular la probabilidad de una secuencia, es necesario calcular una probabilidad diferente de cero a cualquier palabra que no ha sido vista en el conjunto donde se estiman las frecuencias. Una manera para realizar esto es asignar una pequeña masa a todas las palabras que no fueron vistas, a eso se le conoce como suavizado.

Una manera de entender la idea del suavizado es analizaro cuando se pregunta la probabilidad de un segmento, es decir, la probabilidad de una palabra en un conjunto de datos, esta probabilidad está dada por

\[ \mathbb P(w) = \frac{\#(w)}{\sum_\ell \#(\ell)}. \tag{3.2}\]

En el caso del \(k\)-suavizado se le agrega el valor de \(k\) a la frecuencia de cada palabra, es decir, se define \(\hat\#(x) = \#(x) + k\), entonces la Ecuación 3.2 quedaría como \(\mathbb P(w) = \frac{\hat\#(w)}{\sum_\ell \hat\#(\ell)}.\) Realizando la sustituciones, el calculo de la probabilidad quedaría como:

\[ \mathbb P(w) = \frac{\#(w) + k}{\sum_\ell \#(\ell) + k} = \frac{\#(w) + k}{k \mid V \mid + \sum_\ell \#(\ell)}, \]

donde \(\mid V \mid\) es el tamaño del vocabulario.

El caso del modelo de lenguaje, es decir, \(\mathbb P(w_n \mid w_{n-N+1}, \ldots, w_{n-1})\), la ecuación quedaría como:

\[ \mathbb P(w_n \mid w_{n-N+1}, \ldots, w_{n-1}) = \frac{\#(w_{n-N+1}, \ldots, w_{n-1}, w_n) + k}{\#(w_{n-N+1}, \ldots, w_{n-1}) + k\mid V \mid}. \tag{3.3}\]

La clase Frec se puede extender para incluir el cálculo de la frecuencia cuando se utiliza el \(k\)-suavizado tal y como se muestra en el siguiente código.

### Encapsulando la estimación de frecuencias  

La implementación del modelo de lenguaje, en particular de la estimación de las frecuecias descrita en @lst-estimacion-frecuencia se organiza en la clase `Frec` que se muestra en @lst-frec-modelo-lenguaje. La clase recibe el parámetro `N` que indica el tamaño de la ventana y inicializa las variables `voc`, `frase`, y `hist` donde se guardará la frecuencia del vocabulario, de los gramas y de los $N-1$ gramas. 

```{python}
#| echo: true
#| lst-label: lst-frec-modelo-lenguaje
#| lst-cap: Clase que estima la frecuencia de los segmentos de un corpus 

class Frec:
  def __init__(self, N: int=2):
    self.N = N # <1>
    self.voc = Counter() # <2>
    self.frase = Counter() # <3>
    self.hist = Counter() # <4>

  @property
  def segmentador(self):
    try: # <5>
      return self._segmentador # <5>
    except AttributeError: # <5>
      _ = AutoTokenizer.from_pretrained('guillermoruiz/bilmaLAT') # <5>
      self._segmentador = _ # <5>
      return _ # <5>

  def fit(self, X, y=None):
    N = self.N
    voc = self.voc
    for ele in X: # <6>
      tokens = self.segmentar(ele) # <6>
      voc.update(tokens) # <6>
      _ = ["|".join(map(str, lst))
          for lst in zip(*[tokens[i:] for i in range(N)])] # <6>
      self.frase.update(_) # <6>
      _ = ["|".join(map(str, lst)) # <6>
          for lst in zip(*[tokens[i:] for i in range(N-1)])] # <6>
      self.hist.update(_) # <6>
    self.voc = len(voc) # <6>
    if N == 1:
      self.hist = sum(self.frase.values())
    return self

  def segmentar(self, texto):
    _ = self.get_text(texto) # <7>
    return self.segmentador(_).input_ids # <7>

  def get_text(self, ele):
    if isinstance(ele, dict): # <8>
      return ele['text'] # <8>
    return ele

  def frecuencias(self, code, log=False): # <9>
    num = self.frase["|".join(map(str, code))] # <10>
    if self.N == 1: # <11>
      den = self.hist # <12>
    else:
      den = self.hist["|".join(map(str, code[:-1]))] # <13>
    if log: # <14>
      return np.log(num), np.log(den)
    return num, den
```

1. Tamaño de la ventana
2. Tamaño del vocabulario
3. Frecuencia de gramas de tamaño $N$
4. Frecuencia de gramas de tamaño $N-1$
5. Segmentador mediante el modelo bilmaLAT
6. Estimación de frecuencias ver @lst-estimacion-frecuencia
7. Función que segmenta un texto dato
8. Función auxiliar para utilizar una lista de diccionarios
9. Método que calcula la frecuencia de los gramas
10. Frecuencia de secuencia completa ($\#(w_{n-N+1}, \ldots, w_{n-1}, w_n)$)
11. Manejar el caso de $N=1$
12. Denominador de la @eq-prob-palabra
13. Frecuencia de la secuencia de longitud $N-1$ ($\#(w_{n-N+1}, \ldots, w_{n-1})$)
14. Regresa el logaritmo de las frecuencias

### $k$-suavizado {#sec-k-suavizado}

Para poder calcular la probabilidad de una secuencia, es necesario calcular una probabilidad diferente de cero a cualquier palabra que no ha sido vista en el conjunto donde se estiman las frecuencias. Una manera para realizar esto es asignar una pequeña masa a todas las palabras que no fueron vistas, a eso se le conoce como suavizado.

Una manera de entender la idea del suavizado es analizaro cuando se pregunta la probabilidad de un segmento, es decir, la probabilidad de una palabra en un conjunto de datos, esta probabilidad está dada por 

$$
\mathbb P(w) = \frac{\#(w)}{\sum_\ell \#(\ell)}.
$$ {#eq-prob-palabra}

En el caso del $k$-suavizado se le agrega el valor de $k$ a la frecuencia de cada palabra, es decir, se define $\hat\#(x) = \#(x) + k$, entonces la @eq-prob-palabra quedaría como $\mathbb P(w) = \frac{\hat\#(w)}{\sum_\ell \hat\#(\ell)}.$ Realizando la sustituciones, el calculo de la probabilidad quedaría como:

$$
\mathbb P(w) = \frac{\#(w) + k}{\sum_\ell \#(\ell) + k} = \frac{\#(w) + k}{k \mid V \mid + \sum_\ell \#(\ell)},
$$

donde $\mid V \mid$ es el tamaño del vocabulario. 

El caso del modelo de lenguaje, es decir, $\mathbb P(w_n \mid w_{n-N+1}, \ldots, w_{n-1})$, la ecuación quedaría como:

$$
\mathbb P(w_n \mid w_{n-N+1}, \ldots, w_{n-1}) = \frac{\#(w_{n-N+1}, \ldots, w_{n-1}, w_n) + k}{\#(w_{n-N+1}, \ldots, w_{n-1}) + k\mid V \mid}.
$$ {#eq-modelo-qgrams-k}

La clase `Frec` se puede extender para incluir el cálculo de la frecuencia cuando se utiliza el $k$-suavizado  tal y como se muestra en el siguiente código. 

```{python}
#| echo: true
#| lst-label: lst-frec-modelo-lenguaje-k
#| lst-cap: Clase que estima la frecuencia de los segmentos de un corpus usando $k$-suavizado

class Freck(Frec):
  def __init__(self, N: int=2, k_suavizado: float=1):
    super(Freck, self).__init__(N)
    self.k_suavizado = k_suavizado # <1>

  def frecuencias(self, code, log=False):
    num, den = super(Freck, self).frecuencias(code) # <2>
    num = num + self.k_suavizado # <3>
    den = den + self.k_suavizado * self.voc # <4>
    if log:
      return np.log(num), np.log(den)
    return num, den
```

1. Valor del suavizado
2. Frecuencias
3. Numerador de la @eq-modelo-qgrams-k
4. Denominador de la @eq-modelo-qgrams-k

Actualizando la instancia `frec` al uso de la frecuencia con $k$-suavizado

```{python}
#| echo: true

frec = Freck(k_suavizado=0.01).fit(dataset)
```

La función `prob` implementa este tipo de suavizado como se puede observar en el siguiente fragmento.

```{python}
#| echo: true
def prob(txt, k=0.01):
  code = frec.segmentar(txt)[1:-1]
  num, den = frec.frecuencias(code)
  return num / den
```

Se puede observar que la probabilidad de la siguiente frase es menor que cuando no se usa el suavizado, esto es porque una fracción de la masa de probabilidad se está utilizando en elementos no vistos.

```{python}
#| echo: true

```

Complementando lo anterior, la palabra *buenox* presenta una probabilidad mayor a cero utilizando el suavizado.

### Probabilidad de una secuencia

La implementación anterior se puede adaptar para calcular la probabilidad de una frase de cualquier longitud mayor o igual a $N$.

La idea es crear una ventana movil de tamaño $N$ y multiplicar todas las probabilidades obtenidas, considerando que la multiplicación entre números menores a $1$ resulta en un número menor, es más conveniente por razones numéricas el calcular la suma del logaritmo de la probabilidad.

La siguiente función calcula la suma y el promedio del logaritmo de la probabilidad.

```{python}
#| echo: true
#| lst-label: lst-log-prob-frase
#| lst-cap: Logaritmo de la probabilidad de una frase

def log_prob(ele, k=1, average=True):
  frec.k_suavizado = k
  tokens = frec.segmentar(ele)
  acc = 0
  for code in zip(*[tokens[i:] for i in range(N)]): # <1> 
    num, den = frec.frecuencias(code, log=True) # <2>
    acc += num - den
  if average: # <3>
    return acc / len(tokens) # <3>
  return acc
```
1. Iteración por todos los gramas de la frase
2. Logaritmo del numerador y denominador de la @eq-modelo-qgrams-k
3. Calculando el promedio

La función `log_prob` se puede utilizar para calcular la probabilidad de todas las frases en el conjunto utilizado para estimar las frecuencias tal y como se muestra en la siguiente instrucción.

```{python}
#| echo: true
acc = [log_prob(ele) for ele in dataset]
```

La distribución del promedio del logaritmo de probabilidad se muestra en la siguiente figura.

```{python}

df['log-prob'] = acc
df['Conjunto'] = 'dev'
sns.displot(data=df, x='log-prob', hue='Conjunto',
            kind='kde', fill=False)
```

## Encapsulando el modelo de lenguaje de gramas

El modelo de lenguaje de gramas se organiza en la clase `ModeloNGram`. Esta clase hereda la funcionalidad de la clase `Freck` (ver @lst-frec-modelo-lenguaje) y lo complementa implementando el cálculo de la probabilidad de una frase utilizando $k$-suavizado (ver @lst-log-prob-frase).

```{python}
#| echo: true
#| lst-label: lst-modelo-n-gram
#| lst-cap: Modelo de lenguaje de gramas

class ModeloNGram(Freck):
  def __init__(self, N: int=2,
               k_suavizado: float=1,
               promedio: bool=False):
    super(ModeloNGram, self).__init__(N, k_suavizado)
    self.promedio = promedio # <1>

  def _log_prob(self, ele):
    tokens = self.segmentar(ele) # <2>
    acc = 0 # <2>
    for code in zip(*[tokens[i:] for i in range(self.N)]): # <2>
      num, den = self.frecuencias(code, log=True) # <2>
      acc += num - den # <2>
    if self.promedio: # <2>
      return acc / len(tokens) # <2>
    return acc # <2>

  def log_prob(self, X):
    _log_prob = self._log_prob # <3>
    return np.r_[[_log_prob(x) for x in X]] # <3>
``` 

1. Bandera que indica el cálculo del promedio
2. Logaritmo de la probabilidad de la frase, ver @lst-log-prob-frase
3. Calcula el logaritmo de la probabilidad para una lista de textos

::: {.callout-note}
### Ejemplo 
```{python}
#| echo: true

modeloNGram = ModeloNGram(promedio=True).fit(dataset)
```

El logaritmo de la probabilidad de la primera frase de `dataset`, calculada previamente (variable `acc`), tiene un valor de `{python} f'{acc[0]:0.4f}'`. Utilizando la implementación del modelo de lenguaje de gramas (ver @lst-modelo-n-gram), inicializado con `dataset`, y contenido en la variable `modeloNGram` se obtiene el logaritmo mostrado en la siguiente instrucción.

```{python}

```
